## 📂 Struktur Repository
- `Assets/`: Berisi Scene, Script (C#), Material, dan Prefab praktikum (Pertemuan 02 - 07).
- `Dokumentasi/`: Bukti visual (screenshot/video) hasil praktikum dan UTS per pertemuan.
- `ProjectSettings/`: Konfigurasi project (termasuk `EditorBuildSettings.asset` dan `ProjectSettings.asset` sebagai bukti konfigurasi Build & API Level).

## 🚀 Cara Menjalankan Proyek
1. Buka project ini menggunakan **Unity 6.x**.
2. Pastikan platform build diatur ke **Android** di *File > Build Settings*.
3. Buka scene praktikum di folder `Assets/Scenes/` (misal: `Pertemuan02_Diorama.unity`).
4. Tekan **Play** untuk menjalankan di Editor, atau **Build and Run** untuk perangkat Android.
